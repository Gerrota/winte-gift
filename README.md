# 冬将至，我与你｜微信 H5 V5

本版加入程序化动态结霜：四角与屏幕边缘逐步生长树枝状冰晶，冰脉带有冷白高光、微弱蓝色辉光和闪烁冰尘。首页结霜较慢且克制，点击中央雪花后，冰霜在约 3.6 秒内沿边缘明显扩散；原有雪花聚拢、冰晶爆发、冰霜转场和第二幕逐行文字继续保留。

实现为原生 Canvas，无需外部 CDN 或前端框架，适合 GitHub Pages / 微信 WebView。
